# ME LongTeng Grinding Media (Zambia) Ltd — Website Prototype

Premium corporate website demo for **ME LongTeng Grinding Media (Zambia) Ltd (MELTZ)**.

> **Prototype notice:** This is a DEMO/PROTOTYPE for internal presentation and
> management review. All images, statistics, news, jobs, and contact details
> are placeholders and must be reviewed/approved before any production use.

---

## Getting Started

```bash
npm install       # install dependencies
npm run dev       # start the development server
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

Production build:

```bash
npm run build     # create an optimized production build
npm start         # serve the production build
```

## Project Structure

```
src/
  app/                  # Pages (App Router)
    page.tsx            # Homepage
    about/              # About Us
    products/           # Products
    operations/         # Operations
    quality/            # Quality & Technology
    sustainability/     # Sustainability
    careers/            # Careers
    news/               # News index + article pages
    contact/            # Contact
  components/           # Reusable UI components
  data/                 # Structured content (swap for CMS later)
    navigation.ts       # Header/footer navigation
    company.ts          # Company facts, values, operations
    products.ts         # Product data
    news.ts             # News articles
    careers.ts          # Job listings (demo)
    contact.ts          # Contact details (placeholders)
```

## Content Architecture (CMS-Ready)

All site content lives in **structured data files** under `src/data/`.
Components render from this data, so a CMS (Sanity, Strapi, Supabase,
WordPress headless) can be connected later without restructuring components.

## Replacing Demo Images

Placeholder images live in `public/images/` (generated by
`scripts/generate-images.js`). Replace each file with an approved
company photo keeping the same filename, or update the paths referenced in
`src/components/*` and `src/data/*`.

## Required Management Confirmations

The following are placeholders marked `[PLACEHOLDER]` and must be confirmed
before any production use:

- Official email address and telephone number (`src/data/contact.ts`)
- Company statistics (`src/data/company.ts` — `XX+` / `XX MT` values)
- Certifications (`src/app/quality/page.tsx`)
- Article content, job listings, and history timeline dates

## Tech Stack

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS**
- SEO metadata, Open Graph, sitemap, robots.txt, and JSON-LD structured data

## Design Intent

Industrial corporate identity: deep blue (`#003B70`) + white + restrained
gold accent (`#D4A843`), Inter typography, generous whitespace, and strong
visual hierarchy — inspired by international mining-supplier positioning
without copying any existing company's brand.
