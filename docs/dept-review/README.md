# MELTZ Website — Department Content Review Pack

> **Also see:** `docs/CFO-GUIDE.md` — project overview with hosting/running costs
> and CFO sign-off decisions. `09-it.md` covers the technical/go-live side.

Each department is responsible for reviewing **its own sections** of the website
and giving feedback on what content to **add**, **remove**, or **change**.

## How to use

1. Open the file for your department (below).
2. Read **"B. Current content on the site"** — this is exactly what would be
   shown publicly today.
3. Complete **"C. Decisions needed"** where you are the approver.
4. Fill in **"D. Feedback"** at the end of your file (Add / Remove / Change).
5. Send the completed file back to whoever manages the website.

## Who reviews what

| File | Department | Owns these pages/sections |
|---|---|---|
| `01-finance.md` | Finance | All figures: capacity, revenue, statistics, financial claims |
| `02-hr.md` | Human Resources | Careers, jobs, team & leadership, values, people content |
| `03-procurement.md` | Procurement | The entire Procurement page |
| `04-operations.md` | Operations | Operations, manufacturing process, location, facility |
| `05-quality.md` | Quality | Quality & Technology, lab/testing claims, product specs |
| `06-safety-hse.md` | Safety (HSE) | Safety & certification claims, PPE, zero-harm messaging |
| `07-sustainability.md` | Sustainability | Sustainability page, community & environment content |
| `08-sales-marketing.md` | Sales & Marketing | Homepage, products, gallery, news, contact details, branding |
| `09-it.md` | Information Technology (IT) | Hosting, domain, email, contact-form backend, security, maintenance |
| `10-csr.md` | CSR / Community Relations | New CSR page, community content across the site |
